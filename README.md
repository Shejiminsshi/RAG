# Smart Document Analyser - RAG

SmartDoc is an AI-powered Retrieval-Augmented Generation (RAG) based document assistant that allows users to upload PDF documents and interact with them using natural language queries.

The system extracts document content, performs semantic chunking, generates vector embeddings, and retrieves relevant information to produce accurate contextual responses using Large Language Models (LLMs).

---

## Features

* PDF Upload & Processing
* Semantic Chunking
* Vector Embedding Generation
* ChromaDB Vector Storage
* Hybrid Retrieval

  * Semantic Search
  * BM25 Keyword Search
* AI-Powered Question Answering
* Context-Aware Responses
* Interactive User Interface

## Project Architecture

1. Upload PDF Documents
2. Extract & Chunk Text
3. Generate Embeddings
4. Store Vectors in ChromaDB
5. Retrieve Relevant Context
6. Generate AI Responses using LLM

The objective of this project is to enhance document understanding and intelligent information retrieval by integrating semantic search with generative AI models.
